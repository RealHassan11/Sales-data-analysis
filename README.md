# Sales-data-analysis
Sales Data Analysis

Project Overview

This project analyses sales data to understand business performance, identify top-performing products and regions, and uncover insights that can support better business decisions.

Objectives

* Analyse overall sales performance.
* Identify top-performing products.
* Compare sales across regions.
* Present key findings through an Excel dashboard.

Tools Used

* Microsoft Excel
* PivotTables and charts
* Data visualisation and dashboard reporting

Dashboard

The interactive dashboard presents sales performance metrics, product performance, regional comparisons, and key findings.

Key Insights

This section will highlight the most important findings from the analysis, including the leading sales region, best-performing product, and overall sales trends.

Recommendations

Recommendations will be based on the findings from the sales analysis and will focus on improving sales performance and supporting data-driven decisions.

Project Files
